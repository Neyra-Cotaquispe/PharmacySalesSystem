# PharmacySalesSystem 💊

Un sistema de escritorio para la gestión de ventas, control de inventario y facturación en farmacias y boticas. Desarrollado en **C#** con **Windows Forms**.

## 🚀 Características principales
* **Punto de Venta (POS):** Registro de ventas rápidas y generación de comprobantes.
* **Control de Inventario:** Gestión de medicamentos, control de stock disponible y categorías.
* **Gestión de Clientes y Proveedores:** Directorio organizado de contactos para compras y facturación.
* **Reportes y Estadísticas:** Visualización de ventas e historial de transacciones.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C#
* **Interfaz:** Windows Forms (.NET Framework)
* **IDE:** Visual Studio

## 📦 Cómo ejecutar el proyecto
1. Clona este repositorio en tu computadora:
2. Abre la carpeta del proyecto y ejecuta el archivo `PharmacySalesSystem.csproj` en **Visual Studio**.
3. Presiona `F5` o el botón **Iniciar** para ejecutar la aplicación.
