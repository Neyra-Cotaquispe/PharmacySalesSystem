# PharmacySalesSystem 💊

Un sistema de escritorio para la gestión de ventas, control de inventario y facturación en farmacias y boticas. Desarrollado en **C#** con **Windows Forms**.

## 🚀 Características principales
* **Punto de Venta (POS):** Registro de ventas rápidas y generación de comprobantes.
* **Control de Inventario:** Gestión de medicamentos, control de stock disponible y categorías.
* **Gestión de Clientes y Proveedores:** Directorio organizado de contactos para compras y facturación.
* **Reportes y Estadísticas:** Visualización de ventas e historial de transacciones.

## 🛠️ Tecnologías utilizadas
* **Lenguaje:** C#
* **Interfaz:** Windows Forms (.NET Framework)
* **IDE:** Visual Studio

## 📦 Cómo ejecutar la aplicación

### Opción 1: Descarga directa (Para usuarios / Ejecutable)
1. Ve a la sección de [Releases / Lanzamientos](https://github.com/Neyra-Cotaquispe/PharmacySalesSystem/releases).
2. Descarga el archivo `PharmacySalesSystem-v1.0.zip`.
3. Extrae el contenido en tu PC y ejecuta el archivo **`PharmacySalesSystem.exe`**.
> ⚠️ **Nota al ejecutar en Windows:**
> Al abrir por primera vez el ejecutable `PharmacySalesSystem.exe`, es posible que Windows SmartScreen muestre una alerta de seguridad por ser un ejecutable no firmado digitalmente. 
> Para abrirlo: haz clic en **"Más información"** y luego en **"Ejecutar de todos modos"**.
